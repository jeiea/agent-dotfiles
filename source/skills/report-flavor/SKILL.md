---
name: report-flavor
description: 사람에게 코드 변경 사항을 보고할 때 유저 선호사항 확인
---

- 변경으로 영향받는 사용 사례와 관련 테스트·결합 지점을 계층적으로 시각화
- 다음 변경의 결합 지점은 해당 사용 사례 설명에 언제·왜·어떻게 포함
  - 사용·운영 방식, 외부 시스템, 신뢰 경계 변화
  - 배포·실행 단위 사이 결합 변화
    - 함께 변경·복구 필요
    - 호출·데이터·상태·오류 처리·재시도·순서·수명주기
      - 예: 별도 백엔드 API 호출 추가
  - 세션·프로세스보다 오래 유지되는 상태의 추가·이전·복구 및 그 구조
  - 레거시 호환 코드 추가
