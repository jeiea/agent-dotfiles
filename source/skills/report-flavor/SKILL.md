---
name: report-flavor
description: 사람에게 코드에 관련해 보고할 때 유저 선호사항 확인
---

- 변경으로 영향받는 사용 사례와 관련 테스트·결합 지점을 계층적으로 시각화
- 결합 지점: 대상을 하위 요소와 그 관계로 반복 분해할 때 달라지는 관계
  - 최상위부터 양쪽이 다른 버전으로 공존하거나 따로 실패할 수 있는 관계까지 확인
    - 예: 서비스 워커·큐 메시지는 같은 번들이어도 포함, 웹 워커는 제외
  - 해당 사용 사례 설명에 언제·왜·어떻게 포함
  - 관계: 호출·데이터·상태·오류 처리·재시도·순서·수명주기·신뢰·동반 변경·복구
  - 시간 축 관계 포함: 세션·프로세스보다 오래 유지되는 상태, 레거시 호환
  - 예: 사용자·외부 시스템 ↔ 서비스, 서비스 ↔ 새 백엔드 API
