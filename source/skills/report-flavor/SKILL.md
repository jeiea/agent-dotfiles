description: 사람에게 작업 결과·변경 사항을 보고할 때 유저 선호사항 확인
---

- 영향 범위와 복구 난이도를 고려한 중요도순 제시
- 다음 변경은 다른 보고 항목과 분리해 필히 설명
  - 사용·운영 방식, 외부 시스템, 신뢰 경계 변화
  - 배포·실행 단위 사이 결합 변화
    - 함께 변경·복구 필요
    - 호출·데이터·상태·오류 처리·재시도·순서·수명주기
      - 예: 별도 백엔드 API 호출 추가
  - 세션·프로세스보다 오래 유지되는 상태의 추가·이전·복구
  - 레거시 호환 코드 추가
- 추가한 테스트 케이스를 층위가 드러나도록 시각화
