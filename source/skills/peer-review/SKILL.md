# 검토자 선택

- 현재 세션이 Codex면 `claude`, Claude면 `codex` 스킬(플러그인 표기
  `codex-tools:codex`) 우선
- 다른 모델 호출이 어렵다면 서브에이전트 사용 허용
- 가장 강력한 모델 선호

# 원칙

- 편향 방지를 위해 검토자에게 전달할 문맥 최소화
- 산출물 자체, 사용자 요구, 명시 제약, 검토 기준만 전달
- 메인 세션의 추론, 선호 결론, 의심 지점은 기본 전달 금지
- 검토자 응답은 권고. 메인 세션이 최종 판단

# 절차

1. 산출물과 요구사항 정리
2. 요청별 검토 기준 정리
   - 별도 기준 없을 시 다음 기준 사용
     - 요구 충족
     - 오류·모순·누락 확인
3. 각 요청을 독립된 검토자 세션에 의뢰
   - 여러 요청을 한 세션에 통합 금지. 결과 품질 저하
   - 요청 수와 검토자 세션 수 일치 확인

   ```md
   다음 산출물을 수정하지 말고 독립 검토합니다.

   ## 사용자 요구 및 제약

   {원 요청 요약 또는 원문}

   ## 산출물

   {검토 대상}

   ## 검토 기준

   {기준}

   응답 형식:

   # Must fix now:

   현재 범위에서 확인된 요구 위반·결함

   # Consider:

   필수 수정 아닌 개선·취향 제안. 항목별 근거와 기대 이득 명시

   # Follow-up:

   근거 부족·사용자 판단 필요·범위 밖 항목. 필요한 확인 질문·작업 명시
   ```

4. 검토자 출처를 보존해 결과를 중요도별 병합하고 중복 제거
5. 각 지적 독립 검증 후 템플릿·호출처 기준 재판정·처리
   - `Must fix now`: 일괄 반영 후 관련 지적을 낸 검토자 세션 재개, 4단계부터
     반복
   - `Consider`: 요구·명시 선호 부합 시 반영
   - `Follow-up`: 검증 불가, 요구·선호 근거 없는 제안 포함. 중단 질문 없이
     6단계로
   - 오판·무가치: 기각
6. `Follow-up` 보고
   - 항목별 질문 또는 후속 작업, 권고, 보류 영향 범위
   - 검토 불가 시 사유와 잔여 리스크

# 종료 기준

- 검증·병합 후 `Must fix now` 없음
