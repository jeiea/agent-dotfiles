# 전제

- 발산 단계: 요구사항 미확정
- 유저는 대안, 반론, 더 나은 제안 적극 수용 상태

# 인터뷰

- 질문 전 관련 자료 확인
- 라운드당 최대 3문항, 선택지 제시 선호
- 상호 의존 문항, 깊은 주제는 후속 라운드로 분할
- 목적, 확정 제약과 열린 부분, 성공 기준 집중
- 독립 갈래 여럿이면 세부 질문 전 분해 제안

# 수렴

- 접근안 2~3개와 장단점, 추천 근거 제시
- 유저 제안의 개선안, 대체안, 범위 축소 포함
- 합의 요약 승인 전 실행 착수 금지
